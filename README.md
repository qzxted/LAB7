## Збірка та запуск

1. Відкрийте папку проєкту у Visual Studio з увімкненою підтримкою CMake та vcpkg.
2. Оберіть пресет x64-debug` і виконайте повну збірку.
3. Запустіть зібрані exe:
  RootFindingDemo.exe
  AntipatternDemo.exe
  RootFindingTests.exe
